# Thaumic Tinkerer: Reforged

Неофициальная доработанная версия порта Thaumic Tinkerer 2.5 для Minecraft 1.21.1 / NeoForge. Проект основан на порте notlikethiss / overseas и включает KAMI.

Текущий выпуск: **1.1-bbtt.3**.

## Для запуска

Нужны **Minecraft 1.21.1**, **Java 21** и **NeoForge 21.1**; общая сборка проверена на **21.1.264**.

- [Наш Thaumcraft 4: Reforged 1.1-bbtt.30-filter.1](https://github.com/yzs57phbts-web/thaumcraft-4-reforged-dop/releases/tag/1.21.1-bbtt.30-filter.1).
- Curios API **9.5.1** и TerraBlender **4.1.0.8** — зависимости проверенного ядра T4.
- JEI необязателен. Измерение Bedrock и периферия ComputerCraft в этой версии не перенесены. Наличие модуля в исходниках не означает полной проверки всех сочетаний сторонних модов.

Скачайте JAR из [релиза 1.1-bbtt.3](https://github.com/yzs57phbts-web/thaumic-tinkerer-reforged/releases/tag/1.21.1-v1.1-bbtt.3) и положите в `mods` вместе с зависимостями. В папке должна быть одна версия каждого мода.

## Добавили

Перенесённое содержимое, доступное в этой версии:

- Трансвекторные механизмы, притягиватели, воронки, перемещатель блоков и ремонтёр.
- Газы, тёмный кварц, декоративные блоки, растения и стихийные огни.
- Осмотический зачарователь, таблички динамизма, некромантии и дополнительные зачарования.
- Набалдашники, инструменты, бижутерия, ихор, пробуждённое снаряжение и KAMI.

## Пофиксили

- Сохранены нативные рецепты, исследования, переводы и генераторы ресурсов порта.
- В bbtt.3 исправлены использование кровавого клинка во второй руке и отключение щитов ихорным топором.
- Тестовые экспортёры поддерживают расширенные ингредиенты нашего T4.

## Адаптировали

- Экипировка и её эффекты работают с современной боевой системой и Curios.
- Пространственные и сетевые возможности перенесены на API Minecraft 1.21.1 / NeoForge.

## Изменили

- Кровавый клинок получил видимый фантомный щит при пустой второй руке: краткая защита от одного фронтального попадания с платой здоровьем и кулдауном.
- Оба ихорных топора получили согласованные современные параметры урона и скорости атаки.
- Сохранены проклятие кровавого клинка, обычные удары во время кулдауна и локальные настройки эффектов.

## Совместимость и проверки

Выпуск рассчитан на API нашей доработанной версии T4. Совместимость с чистым авторским T4 автоматически не предполагается.

Опубликованный JAR совпадает по SHA256 с выбранным установленным выпуском. Эта комбинация участвовала в проверке полной сборки: загрузка, настоящий Creative-мир, вкладка T4, прокрутка предметов и повтор после перезагрузки ресурсов. Это не означает полного прохождения всех механик каждого аддона. Подробности текущего выпуска и ограничения сохранены в исходниках/уведомлениях проекта; старые отчёты относятся к своим версиям.

## Сборка из исходников

Клонируйте наш T4 рядом и укажите его исходники через `-PthaumcraftDir=../thaumcraft-4-reforged-dop`. Gradle использует composite build. Для генерации из первоисточников отдельно нужны исходные эталоны; они не включены в репозиторий.

```sh
./gradlew build -PthaumcraftDir=../thaumcraft-4-reforged-dop
```

Нужен JDK 21. Машинные пути разработчика, эталонные сторонние JAR, игровые миры и конфиги профиля в репозиторий не включены. Скомпилированный выпуск находится в GitHub Releases; `SHA256SUMS.txt` позволяет проверить скачивание.
